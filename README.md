# 🌸 Plotly Iris Data Visualization

## 📊 Interactive Data Visualization using Plotly

This project demonstrates an interactive and visually appealing **scatter plot of the Iris dataset using Plotly Express**.

The visualization compares **Sepal Width** and **Sepal Length**, while using **Petal Length** for color and marker size to provide additional insights into the dataset.

## 🚀 Project Overview

The main objective of this project is to explore the Iris dataset through an interactive Plotly visualization.

The chart allows us to understand relationships between different flower measurements and identify variations in the dataset through:

* 📌 Sepal Width
* 📌 Sepal Length
* 📌 Petal Length
* 🎨 Color-based visualization
* 📏 Marker-size representation
* 🖱️ Interactive hover information

## 🛠️ Technologies Used

* Python 🐍
* Pandas
* Plotly Express
* Iris Dataset

The visualization includes:

* **Marker Size:** Petal Length
* **Hover Data:** Sepal Width, Sepal Length and Petal Length
* **Color Scale:** Viridis
* **Theme:** Plotly Dark
